# Eval rubric — design mode

Score 0–10 per axis; weighted total must reach 8.0 to pass.

### Design Quality (0.35)
Fidelity to the six reference screenshots: colours used exactly as scoped (orange only on
Claude-branded elements), Menlo texture, spacing rhythm of a real terminal, hierarchy
(white bold vs green vs grey) that makes a long answer scannable.

### Originality (0.30)
Does it feel like a discovered in-joke rather than a template? Welcome banner, sent-message
block, spinner line, stats dot-matrix, Thwip states, footer — each should read as authentic
CLI furniture repurposed with wit.

### Craft (0.25)
No layout shift, no overflow at 360/768/1280, dashed rules align, cards don't nest,
animations 60fps, reduced-motion path works, focus states visible, links real.

### Functionality (0.10)
Boot sequence runs and can be skipped; slash commands (/help /projects … /stats /clear)
work with tab-complete + suggestions; deep links work.
